Willkommen beim digitalen Abstimmungssystem

Mit diesem Tool koennen Sie Abstimmungen in Ihrer Versammlung schnell und einfach digital durchfuehren. So funktioniert es:

  • Richten Sie unten Ihre Versammlung ein und starten Sie diese.
  • Fuer jede Abstimmung wird ein QR-Code auf dem Bildschirm angezeigt.
  • Die Mitglieder scannen den QR-Code mit dem Smartphone und stimmen direkt ab.
  • Das Ergebnis erscheint in Echtzeit auf dem Bildschirm.

Alle Stimmen werden vollstaendig anonym abgegeben. Es werden keine persoenlichen Daten gespeichert und keine Stimme kann einer Person zugeordnet werden. Die Kommunikation laeuft direkt zwischen den Geraeten -- ohne Server, ohne Datenbank.

So funktioniert die Abstimmung

  • Geben Sie oben das Thema und optional eine Beschreibung ein.
  • Waehlen Sie die Abstimmungsart: Ja/Nein/Enthaltung oder eigene Optionen.
  • Optional: Aktivieren Sie ein Zeitlimit -- nach Ablauf wird die Abstimmung automatisch geschlossen.
  • Nach dem Start erscheint ein QR-Code auf dem Bildschirm. Die Mitglieder scannen diesen mit dem Smartphone und geben ihre Stimme ab.
  • Die Ergebnisse werden live auf dem Bildschirm aktualisiert.
  • Sie koennen die Abstimmung jederzeit manuell schliessen oder warten, bis alle abgestimmt haben bzw. das Zeitlimit ablaeuft.

Jede Stimme ist anonym -- es ist nicht erkennbar, wer wie abgestimmt hat. Jedes Geraet kann pro Abstimmungsrunde nur einmal abstimmen.
